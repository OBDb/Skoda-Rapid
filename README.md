# Škoda Rapid

This repository contains signal set configurations for the Škoda Rapid, organized by model year and version. The files are structured to allow for easy differentiation between model generations and other vehicle parameters, ensuring accurate signal mapping for each version of the Škoda Rapid.

The Škoda Rapid is a small family car produced by Czech manufacturer Škoda Auto. The modern Rapid was introduced in 2012 and is available in multiple body styles including a five-door liftback, a five-door hatchback (Spaceback), and a four-door sedan for the Chinese market. Built on the Volkswagen Group's PQ25 platform, the Rapid shares its underpinnings with the Volkswagen Polo and SEAT Toledo, offering practical family car functionality at an affordable price point.
